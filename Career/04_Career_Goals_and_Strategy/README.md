# Direction & Strategy

This folder defines **where you are going and what you are optimizing for**.

It exists to:
- Clarify target roles and trajectories
- Define constraints (compensation, lifestyle, location)
- Prevent reactive or panic-driven decisions

## Start Here

`career-tracks.md` defines the active career tracks, their role target files, and the opportunity routing rule used by `/intake-job`, `/analyze-opportunity`, `/build-resume`, and `/build-application`.

`interviewing-strategy.md` is the durable framework for how interviews are prepared for, conducted, and evaluated; interview prep and post-interview notes in `07_Applications_and_Interviews/` apply it per opportunity.

## How to Use
- Review before applying to roles
- Update when priorities change
- Use as a filter when evaluating opportunities

If this folder is empty or outdated, job seeking will feel chaotic.
