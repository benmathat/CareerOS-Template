# Self-Knowledge & Fit

This folder captures **how you work best** — and **where that comes from**.

It includes:
- Origin story and pre-career background
- Values and principles
- Personality assessments
- Strengths and weaknesses
- Work style preferences and non-negotiables
- [Writing style](writing-style.md): voice standard for submitted resumes and cover letters

## Purpose
- Improve role fit
- Avoid repeating bad matches
- Communicate preferences clearly during interviews

This folder protects long-term satisfaction, not just short-term success.
