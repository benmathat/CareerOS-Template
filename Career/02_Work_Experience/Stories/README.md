# Stories

This folder contains canonical career stories (source of truth).

## Purpose

Capture durable stories that illustrate:
- How you handled challenges
- Leadership moments
- Problem-solving approaches
- Collaboration examples
- Failure and recovery
- Innovation and creativity

## Canonical Rules

- Keep full story detail here (STAR/SOAR, context, action, outcomes, reflection)
- Treat this folder as the long-term story library for your career
- Update facts, metrics, and dates here first
- Link to supporting role/project/metric evidence in `../` sections

## How Interview Prep Uses This

- `07_Applications_and_Interviews/Interview_Prep/story-inventory.md` should reference files in this folder
- Active interview prep can create role-specific notes or condensed versions in `07_Applications_and_Interviews/Interview_Prep/`
- Do not move canonical truth into role-specific prep files
