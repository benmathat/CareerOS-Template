# Cross-Opportunity Execution Layer

This folder holds **shared** application and interview assets — not per-opportunity dumps.

It tracks:
- Application tracker (`Applications/application-tracker.md`)
- Application detail template
- Interview preparation library (`Interview_Prep/`)
- Post-interview evaluations (`Interview_Notes/`, template: `post-interview-evaluation-template.md`)
- Offers and negotiation
- Purpose-built story variants for interview loops in `Interview_Prep/Stories/`

Interview approach is governed by [`../04_Career_Goals_and_Strategy/interviewing-strategy.md`](../04_Career_Goals_and_Strategy/interviewing-strategy.md).

## Purpose
- Maintain a single tracker across opportunities
- Capture reusable interview prep and learning
- Prevent repeating mistakes

Per-opportunity application notes, records, next-steps, resumes, and cover letters live in the matching folder under `../06_Job_Opportunities/<company>_<role>_<date>/`. Tracker rows should point at those paths.

Canonical long-form stories are maintained in `../02_Work_Experience/Stories/` and should be referenced from interview prep materials rather than duplicated here.
