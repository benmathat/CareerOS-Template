# Interview Prep Stories

This folder is reserved for role-specific, temporary interview story variants.

## Purpose

Use this directory only when you need a tactical variant for an active interview loop (for example, condensed versions, role-specific framing, or targeted talking points).

## Canonical Source

Canonical stories live in `../../../02_Work_Experience/Stories/`.

## Rules

- Keep long-term source-of-truth stories in `02_Work_Experience/Stories/`
- Use `../story-inventory.md` to map competencies and interview questions to canonical files
- Archive or remove temporary variants after the active interview cycle ends
